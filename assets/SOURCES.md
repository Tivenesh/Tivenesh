# Asset sources

The Tesseracq Labs mark is the owner's existing brand asset, used with owner authorization. The banner is an original local NumPy/Pillow render using the exact black-T/lime-L vector paths and -12 degree skew from tesseracq-logo-blacklime.svg. Those two paths are extruded into 3D meshes with bevels, perspective projection, directional shading and studio lighting. The surfaces use black and lime materials under that lighting. No grey square, invented symbol, client claim or outside rendering service is used. Archivo is distributed under SIL Open Font License 1.1; the font is rasterized in the banner. [Font source](https://raw.githubusercontent.com/google/fonts/main/ofl/archivo/Archivo%5Bwdth,wght%5D.ttf); [license](https://raw.githubusercontent.com/google/fonts/main/ofl/archivo/OFL.txt).

The name uses Instrument Serif Regular and Instrument Serif Italic from [Google Fonts](https://github.com/google/fonts/tree/main/ofl/instrumentserif), distributed under SIL Open Font License 1.1. The exact font binaries and OFL.txt are retained in local build evidence. Typography is composited only into approved text regions using the frozen original GIF colours.

Technology icon paths come from Simple Icons, distributed under CC0. [Project license](https://github.com/simple-icons/simple-icons/blob/develop/LICENSE.md). The symbols identify technologies used in the verified project catalogue and do not imply endorsement.
